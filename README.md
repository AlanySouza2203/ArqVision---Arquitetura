## 📌 Sobre o projeto

O **ArqVision** é um site institucional desenvolvido para apresentar um estúdio de arquitetura fictício. O objetivo é demonstrar projetos arquitetônicos, apresentar a filosofia do escritório e proporcionar uma experiência visual moderna para visitantes interessados em arquitetura e design.

A aplicação foi construída utilizando **HTML5, CSS3 e JavaScript**, com foco em um layout moderno, imagens em destaque, navegação simples e elementos interativos.

O projeto tem finalidade acadêmica e permite praticar conceitos de desenvolvimento front-end e criação de sites institucionais.

---

## 🎯 Objetivos do projeto

- Praticar HTML, CSS e JavaScript.
- Desenvolver um site institucional.
- Criar um layout moderno e visualmente atrativo.
- Implementar interatividade utilizando JavaScript.
- Trabalhar com galerias e sliders de imagens.
- Simular um portfólio digital para um estúdio de arquitetura.
- Organizar páginas e conteúdos de forma intuitiva.
- Praticar versionamento e publicação de projetos web.

## 💻 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/AlanySouza2203/arq-vision-arquitetura.git
```

### 2. Entre na pasta do projeto

```bash
cd arq-vision-arquitetura
```

### 3. Execute a aplicação

Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão Live Server do Visual Studio Code para executar o site localmente.

> **Observação:** confirme o endereço e o nome do repositório no GitHub antes de utilizar os comandos acima.
